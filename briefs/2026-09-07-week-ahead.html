Check These Out

  • Microsoft's Office Scripts sample gallery — a browsable library of working scripts rather than API documentation. The quick scenarios are the useful part for workpapers: copy multiple tables into one table, generate a workbook table of contents, count blank rows across every sheet, output a range as JSON, save and email a sheet as PDF. Each ships with a downloadable workbook, so you can watch one run against real data before adapting it. Nothing to install — Office Scripts lives in the Automate tab of Excel on the web.
  • GAO's Yellow Book page, worth a re-read for the 2024 edition dates — the 2024 revision takes effect for financial audits of periods beginning on or after December 15, 2025, and separately requires a compliant system of quality management to be designed and implemented by December 15, 2025 with the first evaluation completed by December 15, 2026. That evaluation deadline is the one that sneaks up on small firms, and it is a firm-level obligation rather than an engagement-level one.

Tips

  • Excel: get back to where you were with Ctrl+Backspace. When you have scrolled somewhere far from the active cell — which happens constantly in a 364-account trial balance — Ctrl+Backspace scrolls the window straight back so the active cell is visible again, without moving the selection. It is the counterpart to Ctrl+G, which moves the selection; this one moves only the view. Pair it with Ctrl+End to find the true last used cell when a workbook has phantom rows past the data.
  • AutoHotkey v2: paste as plain text anywhere. Pasting from a PDF or a client email drags fonts, colors and highlighting into your workpaper. This strips it everywhere, including apps that ignore Ctrl+Shift+V: 
    ^+v:: {
    saved := ClipboardAll()
    A_Clipboard := A_Clipboard   ; drops all formatting
    Send "^v"
    Sleep 150
    A_Clipboard := saved         ; restore the original
}
    Save it in your v2 script, reload, and Ctrl+Shift+V pastes clean text system-wide. The A_Clipboard := A_Clipboard line is the whole trick — reassigning the clipboard to itself keeps only the text.
